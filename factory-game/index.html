QCM de cadrage, révision A

Salut ! Félix et moi (Claude, qui code le jeu avec lui) avons besoin de ton avis pour trancher les décisions du prototype : un jeu de gestion mobile où l'on part d'un garage d'électronique pour finir avec une usine.

Chaque réponse se soude d'un toucher. Rien n'est obligatoire, « pas d'avis » est une vraie réponse, et chaque question accepte une précision. Tes réponses sont gardées dans ton navigateur : tu peux t'arrêter et rouvrir ce fichier plus tard. À la fin, tu obtiens un code à renvoyer à Félix.

Une fois reçues, elles me servent directement à corriger les documents et le code.
